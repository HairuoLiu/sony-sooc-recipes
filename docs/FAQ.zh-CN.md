# 常见问题：给你的老索尼相机装胶片配方

<p align="center"><a href="FAQ.md">English</a> · <b>简体中文</b></p>

这是写给手里拿着老索尼、有点心动又有点怕的人看的。问题按大家真实会问的样子来写，每个答案先给结论再讲理由。本文档只写文档、不动代码。

## 安全

### 会不会变砖？会不会动我的固件？

不会，也不会。这个应用走的是索尼自家的 PlayMemories Camera Apps（PMCA）通道，把普通相机设置写进去——就是索尼自家应用商店当年装应用用的那道门。它不刷写、不修补、也不改动固件或引导区。那些在「不支持」清单里的机型，根本收不到任何应用，那是固件签名锁，不是本项目要去对抗的东西。

> **实话实说。**「不会变砖」指的是不改固件。它仍会写入相机的设置存储区，所以请像对待任何一次设置改动那样看待它——而不是像刷固件那样。

### 用了索尼官方没给我这台机器发的东西，保修怎么办？

这件事只有索尼能按你所在地区的规定回答——我们不替它猜。能说的是：安装走的是官方应用通道，非破坏性的，且能干净卸载（应用会离开，已存的配方也能清掉）。它是可逆的，不是永久改动。

> **实话实说。**装第三方应用是否影响保修，取决于当地法律和索尼政策。这套技术本身不留固件痕迹，但我们不会替索尼做任何保修承诺。

### 装到一半断电 / 断连会怎样？

别让它发生——开始前把电池充满、用一根能传数据的线。因为它写的是设置（不是固件），中途出岔子不会变砖；最坏情况是应用装到一半。真遇到了，就在电脑上重跑一次 USB 安装，它会接着走完。

> **实话实说。**这是唯一一个你不该走开的步骤。相机会黑屏、自动切几次模式，那是正常的，不是卡死。以电脑打印的 `Task completed successfully` 为准。

### 能完全恢复到出厂样子吗？怎么恢复？

能。分两层：

- **你存进去的配方：** 在应用里按 `TRASH` + 中心键，然后开关机；或在相机上 `Setup → Setting Reset → Camera Settings Reset`。两种都会让这个风格停下生效。
- **应用本身：** 用相机自己的菜单 —— `MENU → Application → Application Management → Manage and Remove`，选中它移除（部分机型的 `Application Management` 在 `Application List` 下面，多一层）。这会连应用存的设置一起清掉。注意**装它的工具 Sony-PMCA-RE 没有卸载命令**——如果你机器上那个菜单项没有或者是灰的，改走 ADB，完整流程见 [README 的卸载一节](../README.zh-CN.md#卸载)。

所以「回到出厂」永远做得到，不需要特殊工具。

### 会不会让相机变慢？会不会更耗电？

不会。配方只是一组存在相机设置存储区里的数值——拍摄时没有后台进程、没有额外计算。应用只在你打开它预览或存配方时才运行。电量和速度跟你装之前一样。

## 我的相机能不能用？

### 怎么判断我的相机行不行？

按 `MENU`，看有没有一个 **`Application`** 菜单项。有，就说明你的相机能收应用，这套能用；没有 `Application` 菜单，就停下——本仓库任何方法都装不进去。

安装时如果报 `This camera does not support apps. Please check the compatibility list.`，说的就是这件事：工具请相机切到「应用安装模式」，相机拒绝了，安装器只是把这句拒绝转述出来。这是相机侧的回答，不是 APK 的问题——重装、重编多少次都一样。

日志里紧挨着它的上一行 `Switching to app install mode` **不是成功提示**：它在命令发出之前就打印了，只表示「USB 上认到了一台索尼相机，准备发切换命令」。两行连起来读，意思是「连接没问题，切换被拒绝」。而且切换失败会立刻退出，**安装的 APK 根本没被传输出去**——所以这个报错跟你的文件、打包、签名都无关。

> **实话实说。**「没有 `Application` 菜单」等于装不了应用，句号。索尼 2021 年关了自家应用商店，2016 年末之后的机型（a6500 和 a99 II 是最后两台）都是签名固件、拒绝应用——不止本项目装不了，索尼自己都装不进去。

**边界在 2012 年秋。** PMCA 应用平台从 **NEX-5R / NEX-6**（2012 年 8–9 月发布）才开始——那两台第一次带 Android 子系统。更早的 **NEX-7**（2011 年 8 月）、NEX-3 / NEX-5 / NEX-5N / NEX-F3，以及 a3000 / a3500 都没有这个子系统，菜单里根本没有 `Application`。它们和上表「支持」那一列长得很像，但装不了；安装器报 `This camera does not support apps. Please check the compatibility list.` 说的就是这件事。**它们不在「支持」列里不是漏写。**

**这些在真机上跑过吗？** 跑过 —— **α7S II**，同时装着四个品牌包。真机照片见
[README 的真机实拍](../README.zh-CN.md#真机实拍)。「支持」列里其余机型是**平台层面**支持
（机器有这个应用通道），这和逐台实测不是同一个说法——所以这里就这么写。

**这些机器还有别的路吗？** 有一条，但不是本项目的支持路径。配方本质就是一组 Creative Style（基色 + 对比 / 饱和 / 锐度）＋白平衡微调＋DRO 的数值，[`catalog/index.html`](../catalog/index.html) 里逐条都印着，可以照着手动在相机菜单里设——NEX-7 这几项都在（Creative Style 的对比 / 饱和 / 锐度各 ±3 档，白平衡 A–B / G–M 各 ±7 档，DRO Lv1–5）。代价：没有一键存入、没有应用里的预览和批量管理，超出 ±3 的值会被菜单钳到上限，PE（Picture Effect）类配方的档位对应关系未经实测。

### a6400 / a7 III 为什么不行？有没有别的办法？

这些机型没有 `Application` 菜单——索尼大约在 2016 年末去掉了 PMCA 应用通道、改用签名固件。没有软件层面的绕过办法，因为通道在它们身上根本不存在。网上说在 a6400 上跑起来的都是误传——那台机器从来就没法收应用。

> **实话实说。**如果你要的是 a6400 那种胶片味，唯一的现实路径是换一台带内置配置的机器，或者拍平一点后期调色。本仓库帮不了这些相机。

### 需要联网吗？需要电脑吗？

第一次用 USB 安装需要一台电脑（Windows / macOS / Linux），但安装过程**完全离线**——安装器和相机直接对话，不碰网络。安装时不需要联网。（你只需要在电脑上联网一次，下载 APK 和安装器。）

### 装了之后还能正常用相机吗？会不会影响录像？

完全正常。存好的配方作为相机的默认观感，在**所有**模式——P/A/S/M 和录像——下都生效，连应用关着也生效。它不会锁任何菜单，也不改变相机对手卡、对焦、回放的处理。

> **实话实说。**这个观感对录像同样生效。如果你之后要调色，记住配方已经「烘」进 JPEG / 8-bit 输出了；想要没风格的素材去调色，就拍 RAW。

## 这些配方到底做了什么？

### 这些配方和真的胶片一样吗？

不一样——它们是对某种胶片味道的**近似**，不是别家色彩科学的复制品。2014 年的机器存不下富士或柯达的色彩科学，它只能存设置存储区里容得下的东西（Creative Style、饱和度、对比度、锐度、白平衡、曝光补偿、DRO、Picture Effect，外加一个索尼未公开的隐藏色彩矩阵）。我们用这些去贴近。

> **实话实说。**把它想成「有点 Portra 味儿」，而不是「一张 Portra 扫描件」。引擎天花板是真实的：a6000 没有 Picture Profile 菜单、存不下任何色调曲线，所以一切都是用现有转盘拼出来的还原。

### 和富士的胶片模拟是一回事吗？

不是。富士把模拟烧进了传感器管线；本项目只是把菜单设置写进一台老索尼。正因如此，有些东西这里做不到：彩色颗粒、漏光、暗角、LUT 文件、HSL 分通道、真正的青橙分色调、局部处理、Log 曲线。富士的模拟活在這台相机没有的硬件里。

### RAW 会受影响吗？

看配方。Picture Effect（图片效果，PE）类配方——应用里标 **PE** 的——只在 **JPEG** 输出上生效；在 RAW 或 RAW+JPEG 下相机会静默忽略它们。其它配方（Creative Style、白平衡、DRO）是普通相机设置，与文件格式无关都会生效。所以如果你发现效果在 RAW 上「没了」，那是 PE 类配方。

> **实话实说。**想要 Toy Camera、Part Color、Posterization 这类 PE 效果显现，就拍 JPEG（或 RAW+JPEG）。

### 为什么没有颗粒？

因为相机做不了彩色颗粒，它唯一的颗粒来源是黑白的 `rough-mono` 图片效果（`pe=7`）。那能出粗颗粒黑白，但没有彩色颗粒的旋钮。任何在这些机器上号称「胶片颗粒」的，靠的是高感噪点，不是颗粒纹理。

### 为什么有些配方标着 NOT VERIFIED？

本仓库有 7 款配方是作者自写、且**没在实机上验证过**的：`gr-moriyama`、`kodak-vision2-500t`、Toy Camera 暖/冷、Part Color 红、Posterization、Teal Mood。它们在应用里显示 `NOT VERIFIED`。其余 92 款都和上游项目逐值对齐过。

> **实话实说。**在用 NOT VERIFIED 配方前，先拿可丢弃的素材试拍，再放到没法重拍的场合上。它们是在引擎边界内拼的近似，不是坏了——只是没在真机上确认过。

### 能不能自己调？调完还能回到配方吗？

都可以。配方就是一捆菜单值，所以你能在相机自己的菜单里改任意一项——饱和度、白平衡、Creative Style 等等。应用也提供出厂备份/恢复，所以你可以把手改过的配方还原回出厂值。你永远不会被锁死。

> **实话实说。**有个怪点：当 `pe`（图片效果）不为 `off` 时，相机会**忽略 Creative Style**。这是引擎的正常行为，不是 bug——所以 PE 配方和 Creative Style 配方是两族，叠不到一起。

## 日常使用

### 我要不要每次拍照都开着这个 app？

不用。你打开应用一次，预览并存好一个配方；之后它就活在相机设置里，应用关着也生效。只在你想换观感或改数值时才再打开应用。

### 能不能一次装多个配方？切换方便吗？

应用装一次，带走全部 155 款。你一次往相机里**存一款**配方（按中心键），存新的会覆盖上一个。切换很快：打开应用，波轮转到想要的味道，按中心键，完事——不用重装。

> **实话实说。**同一时刻只有一款配方生效，没有「叠几层观感」这回事。如果你想要 A 拍人像、B 拍风景，就在拍摄时于应用里切换。

### 能一次装几个包？相机装得下吗？

**能并存，一份发布里的包全装上也没问题。** 每个包一个独立包名（全量版 `…sonysoocrecipes`，品牌包 `…sonysoocrecipes.<品牌>`），Android 靠包名识别应用，所以它们互不覆盖。一份发布里的 APK 个数 = `catalog/packs.json` 里的品牌包数 + 1（全量版），当前是 9 + 1 = **10 个**。

相机那边的上限是另一个量级：**索尼说大约 20 个**（支持文章 00020843）PlayMemories Camera Apps，且实际个数取决于应用体积——因为应用存在相机内部存储里。我们的 APK 每个约 200 KB，**十个加起来不到 2 MB**，比索尼自家应用小一到两个数量级（它们通常几 MB 起）。所以「装不下」不是你会碰到的问题。

> **实话实说。** 但「装得下」不等于「该装满」，三个代价先摆出来：
>
> 1. **相机内部存的应用越多，开关机越慢。** 这条是索尼自己写明的（支持文章 00020845）：变慢取决于内部存储还剩多少、装了几个应用，属于正常现象而非故障。装满十个不是零成本。
> 2. **装多个包 ≠ 多台相机。** 设置存储区共享，同一时间只有一个配方生效，换包不换配方（见[品牌包 §3](BRAND-PACKS.zh-CN.md#3-设置存储是共享的--一台相机同一时间只能有一个配方生效)）。
> 3. **全量版已经含有全部配方，品牌包是它的子集。** 想要「全都有」，装全量版一个就够；再装九个不会多出一款配方，只会多九张图标和更慢的启动。

### 更新版本要注意什么（签名那件事）？

APK 由 CI 构建，**每次都用一把临时生成、用完即弃的签名密钥**（没配 keystore）。用不同密钥签的 APK **无法覆盖安装**——你会看到 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`。解决办法：先在相机应用管理里卸载同名应用，再装新的（卸载会清掉应用存的设置，所以之后要重新存一次你的配方）。

> **实话实说。**应用里显示的版本号是**上游**版本，不是本仓库的 tag。以 GitHub 的 release tag 为准，别信应用内的数字。

### 用 Wi-Fi ADB 安全吗？

只在可信网络、短时间用才安全。开启 ADB（通过 OpenMemories:Tweak）会让相机在局域网 5555 端口监听调试命令——那个网络上的任何机器都能对你的相机跑 `adb`，包括卸载应用、读存储卡。在你自己的 Wi-Fi 上用，用完 `adb disconnect` **并且** 在 Tweak 里把 ADB 关掉。`adb disconnect` 只断了你电脑这一侧；相机上的守护进程会一直开着，直到你在 Tweak 里禁用它。

> **实话实说。**第一次安装无论如何都走 USB——Tweak 本身也是用 USB 装的。ADB 只是反复重装的便利项，不是必需。在公共或访客网络上，留在 USB 通道。

## 如果我就是想找某款口味，该从哪开始？

打开滤镜浏览器 [`catalog/index.html`](catalog/index.html)——一个单文件、无依赖的页面，列出全部 155 款配方及其分组和色调。按品牌（柯达、富士、理光 GR、伊尔福……）、按彩色/黑白、或按引擎筛选，找到名字对得上的那款。

如果拿不准，从你已经喜欢的味道入手：暖调日常负片？试 `kodak-portra-400` 或 `fuji-superia-400`。阴郁电影夜景？试 `cinestill-800t`。干净黑白？试 `ilford-hp5` 或 `acros`。挑一款、装上、拍一卷，再从那里换——重点就在于换下一款观感，你只付出转一下波轮的成本。
